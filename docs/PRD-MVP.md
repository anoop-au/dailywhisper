# Daily Whisper — PRD + MVP Scope

## Purpose
Calm, on-device Android notes app for short and longer whispers. Capture text (or live dictation), keep it local, translate offline, and manage notes with history, soft-delete, archive, highlight and search.

## Target users
People who want a private, fast notes surface on Android — especially those who dictate in one language and want to read or share in another. Primary context: Australia, with support for common languages spoken there.

## Core value
- Notes never leave the phone.
- Offline translation (Opus-MT for the chosen pair once its model is downloaded, ML Kit otherwise).
- Soft-delete + recoverable history.
- Minimal friction after a short first-run setup.

## MVP features (implemented or in current code)
- Notes with append-only versioning (`note_versions`). Feed shows latest; History lists versions; Restore creates a new version.
- Soft-delete (status = deleted, deleted_at) with an Undo bar. Deleted view (⋮ → Deleted, most recent first) with Restore. Hard delete ("Delete forever", removes the note's history too) only from that view, with confirm. No expiry.
- Archive (status = archived). Separate list; open to restore.
- Highlight colour on notes (configurable default).
- FTS4 full-text search (prefix per word) across active notes (optional include archived; deleted never).
- First-run setup (once): welcome screen (2.5 s, adjustable), source language, target language, explicit region, data-residency disclosure for live dictation (plain language: no provider, endpoint, engine or model names on setup screens; "Full details are in the Privacy Policy."), "You can change these later in Settings.", then notes list. The language steps show a short list (the phone's language first, then the current choice and English) with a search box and an "All languages" link. The last screen offers, optionally, the matching offline speech pack with its size ("Dictate without internet (optional)"; skippable, plain words, no provider or model names). The chosen pair's Opus-MT model starts downloading in the background after the region step.
- Offline translation:
  - ML Kit as the fallback (until Opus-MT is ready, for pairs Opus-MT lacks such as English→Japanese/Korean, or if Opus-MT fails). Language packs (~30 MB each) download on first use.
  - Opus-MT (Helsinki-NLP, int8 ONNX, ONNX Runtime 1.28.0) for the pair derived from source + target, direct or through English. Background download on any network (mobile data included; "Download on Wi-Fi only" is off by default), Range resume, SHA-256 check. 4-beam search by default (Settings → Opus-MT search width).
  - Malayalam (60th language, Opus-MT only: ML Kit has none): en↔ml models (85 MB / 147 MB) converted by us from Helsinki-NLP opus-mt-en-ml / opus-mt-ml-en and hosted on Hugging Face (akm9191, Apache-2.0); other languages pivot through English (e.g. Malayalam → Chinese). Until downloaded, or if Opus-MT can't run on the phone, translation says so plainly instead of falling back. Known weakness: Malayalam with English words mixed in (code-mixed, e.g. Sarvam's "Keep English words in English" output) translates badly ("ഞാൻ office-ൽ നിന്ന് late ആയി വന്നു." → "I came from 1983 to 1980."); English → Malayalam sometimes drops words.
  - Open note in reading view; tap text to translate. Result panel with Copy / Keep both / Replace (Undo). Pencil or long-press to edit.
- Share (system share sheet, plain text: from the note header and the list's long-press menu).
- Multi-select soft-delete (long-press menu → Select → ticks + top bar ✕ / "N selected" / Select all / Delete; one Undo bar).
- Live dictation with 4 BYOK speech slots: Deepgram (slot 1, regional endpoints, mip_opt_out) and Sarvam AI (slot 2, India; adds Malayalam and 10 other Indian languages Deepgram lacks) with automatic fallback; slot 3 "On this phone" (on-device speech-to-text with Sherpa-ONNX, no key, audio never leaves the phone) once a speech pack is downloaded; slot 4 empty. Online order Deepgram → Sarvam AI → On this phone. With no internet at the start the mic goes straight to On this phone ("No internet, using offline mode"); if the connection drops mid-session it carries on there ("Connection lost, using offline mode"; Settings → On this phone → "Switch when the internet drops", default on). Speech packs: English (73 MB, word by word as you speak), Malayalam (139 MB, a sentence at a time after each pause) and "All languages (1,600+)" (366 MB, sentence at a time, lower quality), managed in Settings → On this phone → Speech packs (suggested for the phone's language first, then installed with size and Delete, then available). Language list offers "Multilingual (Deepgram)" and "Auto (Sarvam AI)" (Sarvam's own detection for Malayalam, English and other Indian languages, slot 2; falls back to Deepgram Multilingual when Sarvam AI is off or not set up), with an optional "Keep English words in English" switch (Sarvam code-mixed output, off by default). Adjustable pause before a sentence ends (default 1.3 s). Mic hidden until residency consent if required.
- Settings for translation languages, model management, region/consent, theme, highlight default, search options, etc. Simple layout (Oct 2026): Dictation, Speech providers · tried in order (a page per provider: on/off, key, model, formatting or output, where audio goes), Notes, then Composer, Translation, Look & layout, Advanced.

## Explicitly out of MVP (later)
- Gesture customisation (swipe-to-share etc.).
- A provider for speech slot 4 (the slot exists, empty).
- Full commercial monetisation tiers (coffee / pizza / biriyani).
- Broader model choices beyond ML Kit + Opus-MT pairs.
- Cloud sync or multi-device.

## Success criteria for MVP
- User can complete first-run, create notes, translate offline, soft-delete and recover, search, archive, highlight, share, and multi-select delete without data leaving the device (except consented live-dictation audio).
- App remains usable on 64-bit Android devices (Android 11+, arm64) with the current size footprint: release APK about 51 MB (ML Kit 16 MB + ONNX Runtime 29 MB native + Sherpa-ONNX 3.3 MB, sharing the same ONNX Runtime), plus 73–366 MB per offline speech pack and ~85–150 MB per Opus-MT model and ~30 MB per ML Kit language pack once downloaded.
